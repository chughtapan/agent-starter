# Holding reply

**Intent:** The asker knows the mail landed and roughly when to expect an answer; nobody polls.

**Evidence:** The question needs a decision, a fact, or a commitment only the owner has.

**Decision:** Answer later, but say so now.

**Execution:** One reply in-thread: "waiting on <Owner>; will answer here" (with a rough time if known). Then the real answer in the same thread when it comes. Never a second holding reply.

**Failure modes:** Silence; hedged half-answers; a new thread for the answer.
