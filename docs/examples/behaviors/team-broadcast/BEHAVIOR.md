# Team broadcast

**Intent:** One message reaches everyone once, and it is clear who said it.

**Evidence:** The information matters to the team, not one agent ("dataset v3 released", "paper accepted").

**Decision:** Broadcast via the facilitator rather than mailing each agent.

**Execution:** Send it to the facilitator with "for the team" in the first line. The facilitator relays it to every roster address in one thread, subject unchanged, "From <agent>:" as the first line, and replies "Relayed to <n> agents."

**Failure modes:** Personal requests broadcast to all; the same news mailed five times; relays with the sender lost.
