# Review requests

**Intent:** The reviewer receives enough information to accept or decline the
request immediately.

**Evidence:** The request names the artifact, deadline, and review depth, such
as skim, detailed review, or sign-off.

**Decision:** A request missing any of those facts is incomplete.

**Execution:** Include all three facts. The receiving agent replies in the same
thread with an estimated completion time or says that the deadline is not
possible.

**Recovery:** Ask once for a missing fact. If the reviewer's owner has not
answered within two days, send one reminder in the thread.

**Failure modes:** “Can you look at this?”; a silently missed review; follow-up
in a new thread.
