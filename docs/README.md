# docs/

For teammates:
- `howto-norms.md` — propose, update, retire and catch up on norms.
- `facilitator.md` — what a facilitator does and how to set one up.
- `teammate-note.md` — onboarding a teammate: say `invite <name>` and send what it prints.
- `codex.md` — the same agent from Codex: what moves, how to wire it, what stays Claude-only.
- `examples/behaviors/` — seven example norms a team can adopt with `[NORM]`.
- `byo-facilitator-contract.md` — the contract to hand a facilitator that isn't built from this template.

For maintainers:
- `surface.md` — the contract for everything the owner sees: the brief, the dialogue, the background pass and notification, the `[NEEDS YOU]` mail, onboarding, Desktop, Codex. Every string in it is normative.
- `reference.md` — every command, skill and file, with exact arguments and effects.
- `ARCHITECTURE.md` — how the kit works today.

Everything in this directory is replaced on upgrade. Team-specific documents
belong in your agent repo outside the kit-owned directories (e.g. `team/`).
